QWTF Live Race Server
====================

To play:

Download FortressOne FTE Client (https://github.com/FortressOne/fte-config/releases/)

Use normal QWTF class binds. Bind 'race' and 'unrace' to start or stop a race.

If 'race' is selected before class, Soldier will be chosen by default.

Change map with 'cmd votemap mapname'

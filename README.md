QWTF Live Race Server
====================

The server files here are already compiled and run on Windows. Click run_race_server_win.bat to start the server.

Add maps to fortress/maps.

Gameplay operates like QWTF Live (https://github.com/QWTF-Live). 

The objective is to go from spawn > flag > capture as fast as possible. Any map with a capture goal works.

To play:

Download FortressOne FTE Client (https://github.com/FortressOne/fte-config/releases/)

Use normal QuakeWorld Team Fortress binds. Bind 'race' and 'unrace' to start or stop a race.

If 'race' is selected before class, Soldier will be chosen by default.

Change map with 'cmd votemap mapname' or the new Map Menu
